Added ``rruleset.explain()``, which produces an explicit explanation of the set's candidates within a bounded half-open range ``[start, end)``. Each distinct instant in the range records all of its ``rrule`` / ``rdate`` sources and, if excluded, the ``exrule`` / ``exdate`` that excludes it. Candidates at the same UTC instant from different sources are merged into one record (de-duplicated) while retaining every source. The range generators are bounded by ``end`` so the infinite future is never walked, and the recurrence algorithm itself is not replaced.
