Added an explicit strict candidate entry point, :func:`dateutil.parser.parse_candidates`, which interprets a date string with an ambiguous day/month order under each declared candidate (``MDY``/``DMY``), applies the caller's date range and default-field policy, and reports whether the result is unique, ambiguous or has no solution. Unlike :func:`dateutil.parser.parse`, it requires an injected ``default`` datetime and never reads today's date; distinct orders resolving to the same actual date are merged as sources.
